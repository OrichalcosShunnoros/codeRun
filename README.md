## EN-lang

# PyRunner

PyRunner is a web application that allows you to run Python code directly in the browser using Pyodide.

## 📌 Features
- Support for running Python code in real-time.
- Simple and fast interface.
- Based on Pyodide, allowing you to run code without the need for a backend.
- Option to switch between programming languages.

## 🚀 How it works
PyRunner uses **Pyodide**, a Python implementation in WebAssembly, to run Python code directly in the browser.
Code entered in the editor is interpreted and executed, displaying the output in real-time.

## 🛠️ Installation and Use

### 1️⃣ Prerequisites
PyRunner does not require any dependencies to be installed. You only need a modern browser that supports WebAssembly.

### 2️⃣ Clone the repository
```bash
git clone https://github.com/your_user/py-runner.git
cd py-runner
```

### 3️⃣ Run the application
Open the `index.html` file in your browser:

```bash
xdg-open index.html # Linux
open index.html # macOS
start index.html # Windows
```

## ⚠️ Considerations
- Make sure you are connected to the Internet to load Pyodide from the CDN.
- There may be limitations in running certain Python libraries due to WebAssembly environment restrictions.
- If the console shows no output, check the loading of `pyodide.js` in the browser console.

# PyRunner

PyRunner es una aplicación web que permite ejecutar código Python directamente en el navegador utilizando Pyodide. 

## 📌 Características
- Soporte para ejecutar código Python en tiempo real.
- Interfaz simple y rápida.
- Basado en Pyodide, lo que permite ejecutar código sin necesidad de un backend.
- Opción para cambiar entre lenguajes de programación.

## 🚀 Cómo funciona
PyRunner utiliza **Pyodide**, una implementación de Python en WebAssembly, para ejecutar código Python directamente en el navegador. 
El código ingresado en el editor es interpretado y ejecutado, mostrando la salida en tiempo real.

## 🛠️ Instalación y Uso

### 1️⃣ Requisitos previos
PyRunner no requiere instalación de dependencias. Solo necesitas un navegador moderno compatible con WebAssembly.

### 2️⃣ Clonar el repositorio
```bash
git clone https://github.com/tu_usuario/py-runner.git
cd py-runner
```

### 3️⃣ Ejecutar la aplicación
Abre el archivo `index.html` en tu navegador:

```bash
xdg-open index.html  # Linux
open index.html      # macOS
start index.html     # Windows
```

## ⚠️ Consideraciones
- Asegúrate de estar conectado a Internet para cargar Pyodide desde la CDN.
- Puede haber limitaciones en la ejecución de ciertas bibliotecas de Python debido a las restricciones del entorno WebAssembly.
- Si la consola no muestra salida, revisa la carga de `pyodide.js` en la consola del navegador.
